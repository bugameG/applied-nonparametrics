A repository dedicated to the study and application of
nonparametric statistical methods using R.

---

```
CONTENTS
--------
Assignments/   coursework problems & solutions (R Markdown)
Notes/         lecture notes and reference material
```

---

```
TOPICS COVERED
--------------
  - Sign Test & Wilcoxon Signed-Rank Test
  - Mann-Whitney U & Kolmogorov-Smirnov (Two-Sample)
  - Kruskal-Wallis H Test
  - Friedman Test & Cochran's Q Test
  - Jonckheere-Terpstra Test (Ordered Alternatives)
  - Post-hoc Procedures (Bonferroni Correction)
  - Effect Sizes & Confidence Intervals (Hodges-Lehmann)
```
